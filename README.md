# riodejaneiro.vip — The Marvelous City, unlocked

A premium, bilingual (🇺🇸 EN / 🇧🇷 PT) travel portal for **Rio de Janeiro**, built for both
international visitors and Brazilians. Carnival, Réveillon, nightlife, sightseeing, where to
stay & eat, VIP experiences — plus honest, practical answers on safety and getting here.

Engineered for **perfect SEO**: per-page metadata, canonical + `hreflang` alternates,
JSON-LD structured data (Article, FAQ, Breadcrumb, Organization), a generated `sitemap.xml`
and `robots.txt`, and a fully static, fast export.

## Stack

- **Next.js 14** (App Router) — static export (`output: 'export'`)
- **Tailwind CSS** — custom Rio brand system (ocean night, sunset gold, tropical accents)
- **TypeScript** throughout
- **next/font** — Fraunces (display) + Inter (body)
- Zero runtime dependencies beyond React — deploys anywhere static (Vercel, Netlify,
  Cloudflare Pages, S3, etc.)

## Getting started

```bash
pnpm install
pnpm dev            # http://localhost:3000/en
pnpm build          # static export to ./out  (+ root redirect)
node scripts/serve.mjs   # preview the built ./out at http://localhost:4321
```

## Project structure

```
src/
  app/
    [lang]/              # locale root (en, pt) — root layout lives here
      layout.tsx         # <html>, fonts, header/footer, site-wide JSON-LD
      page.tsx           # homepage
      [slug]/page.tsx    # data-driven guide pages (12 guides × 2 locales)
    sitemap.ts           # generated sitemap.xml with hreflang alternates
    robots.ts            # generated robots.txt
    globals.css          # Tailwind + brand component classes
  components/            # Header, Footer, Logo, CategoryCard, JsonLd…
  content/
    types.ts             # content model (Guide → Section → Item, FAQ)
    guides/*.ts          # the actual bilingual content for each guide
    index.ts             # aggregation + lookup helpers
  lib/
    site.ts              # global config (domain, locales, social, OG)
    seo.ts               # buildMetadata() — canonical + hreflang + OG/Twitter
    i18n.ts              # UI dictionary + bilingual content helpers
    nav.ts               # lightweight navigation config
scripts/
  gen-art.mjs            # generates the branded SVG scene art (see below)
  postbuild.mjs          # writes the / → /en redirect into ./out
  serve.mjs              # tiny static server to preview ./out
public/img/              # generated brand art (one scene per guide + hero + OG)
```

## Content

All copy is **bilingual** and lives in `src/content/guides/*.ts`. Each guide is a typed
object with SEO metadata, an intro, sections of cards, FAQs and related links — so adding or
editing content never touches the rendering code. The 12 guides:

**Experiences:** Sightseeing · Things to do · Carnival · Réveillon · Parties & Nightlife ·
Where to stay · Where to eat · VIP experiences
**Plan your trip:** Is Rio safe? · How to get here · Getting around · Best time to visit

Facts (Carnival 2027 dates, the 2025 visa change for US/CA/AU, metro fares, Michelin status,
VIP pricing, etc.) were sourced from current research and should be re-verified before each
season, as noted in the on-page disclaimers.

## Imagery — replacing the placeholder art

The site ships with **self-contained branded SVG scene art** (a stylized Rio skyline —
Sugarloaf, Corcovado, sun and sea — themed per category) generated by
`scripts/gen-art.mjs` into `public/img/`. This guarantees a polished look with **no external
image dependencies**.

To use real or **AI-generated ultra-realistic photography**, simply drop files into
`public/img/` with the same names (e.g. `carnaval.jpg`) and update the `hero` field of the
matching guide in `src/content/guides/*.ts`. For best social-share previews, replace
`public/img/og.svg` with a **1200×630 raster** (`og.jpg`) and point `SITE.ogImage` at it in
`src/lib/site.ts`.

## SEO checklist (built in)

- ✅ Unique `<title>` + meta description per page, in both languages
- ✅ Canonical URLs and `hreflang` alternates (`en`, `pt`, `x-default`)
- ✅ Open Graph + Twitter cards
- ✅ JSON-LD: `WebSite`, `Organization`/`TravelAgency`, `Article`, `FAQPage`, `BreadcrumbList`
- ✅ `sitemap.xml` (with locale alternates) and `robots.txt`
- ✅ Semantic headings, fast static HTML, responsive, accessible
- ✅ `/` redirects to the visitor's language (defaults to English)

## Deploy

Any static host. Point the build output (`./out`) at your host and map the
`riodejaneiro.vip` domain.

- **Vercel / Netlify:** framework preset Next.js (static export), build `pnpm build`,
  output `out`.
- **Cloudflare Pages / S3 + CDN:** upload `./out`.
